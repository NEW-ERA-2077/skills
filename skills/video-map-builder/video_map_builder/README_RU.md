# Video Map Builder 2.0

Локальный инструмент для построения карты видео из кадров с точными временными отметками. Создаёт контакт-листы (изображения с сеткой кадров) и файлы навигации. Подходит для ручного изучения монтажа и последующего использования ИИ-агентами. **Оригинальное видео не изменяется.**

## 1. Требования и установка

- Windows 10/11 или Linux.
- Python **3.10 или новее**.
- FFmpeg и FFprobe (из одного комплекта FFmpeg).
- Библиотека Pillow.

Распакуйте архив в удобную папку. Откройте терминал **в этой папке** (там, где находится `video_map_builder.py`). Выполните:

**Windows (PowerShell / CMD):**

```powershell
py -3 -m pip install -r requirements.txt
py -3 video_map_builder.py --help
```

**Linux:**

```bash
python3 -m pip install -r requirements.txt
python3 video_map_builder.py --help
```

Проверьте, что FFmpeg доступен:

```powershell
ffmpeg -version
ffprobe -version
```

Если команды не находятся, установите FFmpeg и добавьте его каталог `bin` в переменную среды `PATH`. Либо поместите `ffmpeg.exe` и `ffprobe.exe` рядом с `video_map_builder.py` (Windows), или используйте параметры `--ffmpeg` и `--ffprobe` с полными путями. Также поддерживается папка `tools/ffmpeg/bin/` внутри распакованного архива.

> Во всех командах ниже используется Windows-форма `py -3`. На Linux замените её на `python3`. Пути в кавычках могут содержать пробелы, кириллицу и другие символы.

## 2. Самое простое: создать карту всего видео

```powershell
py -3 video_map_builder.py "D:\Videos\reference.mp4"
```

По умолчанию формируется три слоя:

1. `01_overview_*` — общий обзор: 1 кадр каждые 5 секунд.
2. `02_main_*` — основная карта: 2 кадра в секунду по всему ролику.
3. `03_hook_*` — первые 30 секунд: 4 кадра в секунду.

Карта создаётся рядом с видео в папке `reference_video_map/`. Если такая папка уже существует, для нового проекта выбирается свободное имя (`reference_video_map_2` и т. д.). Данные существующих проектов не перезаписываются.

Если нужны кадры отдельными файлами, добавьте `--keep-frames`. Без него создаются контакт-листы, а временные промежуточные кадры удаляются после успешной сборки.

### Плотный анализ уже при первом запуске

```powershell
py -3 video_map_builder.py "D:\Videos\reference.mp4" --detail "12:52-14:22@5" --detail "17:10-17:30@8"
```

Создаст стандартную карту плюс подробные карты указанных диапазонов. Параметр `--detail` существовал и в предыдущей версии и сохранён.

## 3. Обработать ТОЛЬКО промежуток времени

Например, с **12:52 до 14:22** — ни раньше, ни позже:

```powershell
py -3 video_map_builder.py "D:\Videos\reference.mp4" --start 12:52 --end 14:22 --fps 4
```

Здесь извлекаются кадры только диапазона `[12:52; 14:22)` с частотой 4 кадра/с. Параметр `--end` — новый. Время можно вводить в виде `12:52`, `00:12:52` или `00:12:52.500`.

Также работают старые параметры:

```powershell
py -3 video_map_builder.py "D:\Videos\reference.mp4" --fps 3
py -3 video_map_builder.py "D:\Videos\reference.mp4" --interval 2
py -3 video_map_builder.py "D:\Videos\reference.mp4" --fps 2 --start 120 --duration 90
```

`--fps` и `--interval` взаимоисключающие. В первом случае указывается число кадров за секунду, во втором — интервал между кадрами в секундах. `--start` и `--end` работают в режиме одиночного прохода (`--fps` или `--interval`).

## 4. Дополнить УЖЕ СОЗДАННУЮ карту без пересчёта

Предположим, папка проекта — `D:\Videos\reference_video_map`. Добавить подробные кадры с 12:52 до 14:22:

```powershell
py -3 video_map_builder.py extend --project "D:\Videos\reference_video_map" --start 12:52 --end 14:22 --fps 5
```

Добавится отдельный проход `extra_*` внутри **того же проекта**. Существующие листы и кадры сохраняются без изменений. `manifest.json` дополняется.

**Если диапазон с такими же началом, концом и частотой уже обработан — программа использует готовые файлы и не запускает обработку повторно.**

Можно указать шаг вместо частоты:

```powershell
py -3 video_map_builder.py extend --project "D:\Videos\reference_video_map" --start 12:52 --end 14:22 --interval 0.5
```

Важное ограничение: диапазон не должен выходить за фактическую длительность видео. Команда `extend` рассчитана на проекты текущей и предыдущей версий с `manifest.json`.

## 5. Найти нужные листы по диапазону времени

```powershell
py -3 video_map_builder.py locate --project "D:\Videos\reference_video_map" --start 12:52 --end 14:22
```

Выводит список соответствующих **контакт-листов** с диапазонами ячеек, затем точные временные отметки кадров, номера строк и столбцов.

По умолчанию подробный список ограничен **50 кадрами**, чтобы не перегружать терминал и контекст ИИ. При этом список подходящих листов показывается целиком. Для подробной выдачи:

```powershell
py -3 video_map_builder.py locate --project "D:\Videos\reference_video_map" --start 12:52 --end 14:22 --limit 200
```

Поиск работает по **уже имеющимся кадрам**, не извлекает новые и не меняет файлы.

## 6. Получить один кадр в ИСХОДНОМ разрешении

```powershell
py -3 video_map_builder.py frame --project "D:\Videos\reference_video_map" --at 12:54.500
```

Сохраняет полноценный кадр оригинального видео в `original_frames/frame_00-12-54_500.png` внутри проекта — без уменьшения до 320 пикселей и без подписей. Если файл уже есть, повторно извлекать его не нужно.

Изменить расположение и формат изображения:

```powershell
py -3 video_map_builder.py frame --project "D:\Videos\reference_video_map" --at 12:54.500 --output "D:\Frames\example.png"
```

Если изображение существует и вы **осознанно** хотите заменить его, добавьте `--force`.

FFmpeg извлекает реальный исходный кадр, соответствующий или ближайший следующий по времени. Для видео с переменной частотой кадров временная точка может немного отличаться от запрошенной.

## 7. Предварительно оценить число кадров и листов

```powershell
py -3 video_map_builder.py plan "D:\Videos\reference.mp4"
py -3 video_map_builder.py plan "D:\Videos\reference.mp4" --start 12:52 --end 14:22 --fps 5
```

Команда только читает сведения о видео через FFprobe. Папки с результатами не создаёт. Количество кадров/листов — **оценка**: фактическая выборка зависит от временных отметок в видеопотоке.

## 8. Возобновить работу и использовать готовые проходы

Если генерация прервалась, запустите **точно ту же команду**, добавив `--resume`:

```powershell
py -3 video_map_builder.py "D:\Videos\reference.mp4" --resume
```

Если при первом запуске использовалась `--output`, повторите тот же путь:

```powershell
py -3 video_map_builder.py "D:\Videos\reference.mp4" --output "D:\Maps\reference" --resume
```

Поддерживается и синоним `--reuse`. Готовые проходы проверяются и пропускаются, незавершённые создаются заново. Если ошибка случилась между завершением прохода и записью общего описания, проход восстанавливается из `pass.json`.

**Нельзя продолжить проект с другим исходным файлом или другими параметрами оформления.** При изменении параметров нужно создать новый проект. Для дополнительных временных участков используйте `extend`.

Если программа обнаружит **повреждённый** уже завершённый проход, она остановится, а не удалит его молча. Причину можно проверить вручную; далее можно удалить только повреждённую папку прохода и выполнить `--resume`.

## 9. Краткий вывод для программ и агентов

К любому режиму добавьте `--json`:

```powershell
py -3 video_map_builder.py status --project "D:\Videos\reference_video_map" --json
py -3 video_map_builder.py locate --project "D:\Videos\reference_video_map" --start 12:52 --end 14:22 --json
```

Стандартный вывод (`stdout`) содержит **один объект JSON**. Промежуточные сообщения отправляются в поток ошибок (`stderr`). При ошибке программа возвращает ненулевой код завершения; после начала обработки диагностический ответ также записывается в JSON. Это удобно для самостоятельного вызова из программ.

## 10. Где находятся результаты

```text
reference_video_map/
  manifest.json                   состояние, настройки, проходы, список листов
  README_MAP.txt                  краткая инструкция к конкретной карте
  01_overview_every_5s/
    INFO.txt
    pass.json                     данные для восстановления
    frames.csv                    таймкод → контакт-лист → строка → колонка
    sheets/
      sheet_0001_....jpg
  02_main_2fps/
    ...
  03_hook_first_30s_4fps/
    ...
  extra_01_.../                  добавленные подробные фрагменты
    ...
  original_frames/               по мере вызова команды frame
    frame_00-12-54_500.png
```

В `frames.csv` находятся столбцы `index`, `seconds`, `timestamp`, `filename`, `sheet`, `cell`, `row`, `column`, `frame_path`.

- `sheet` — существующий лист в папке `sheets/`.
- `filename` и `frame_path` заполнены **только если** выбрано `--keep-frames`. В противном случае они пусты, чтобы не создавать ссылки на удалённые файлы.
- `manifest.json` обновляется после каждого завершённого прохода. Для незавершённого проекта состояние `incomplete`.

## 11. Дополнительные настройки

| Параметр | Значение |
|---|---|
| `--main-fps 3` | 3 кадра/с в главной карте |
| `--overview-interval 10` | обзор каждые 10 секунд |
| `--no-overview` / `--no-hook` | отключить соответствующий слой |
| `--frames-per-sheet 30 --columns 6` | до 30 кадров на листе в 6 колонок |
| `--thumb-width 480` | увеличить миниатюры для контакт-листов |
| `--timestamp-position bottom-right` | переместить подпись времени |
| `--show-frame-number` | дополнить подпись номером кадра |
| `--format webp --quality 85` | сохранить контакт-листы в WebP |
| `--keep-frames` | сохранить отдельные уменьшенные JPG-кадры |
| `--timeout 7200` | увеличить предел работы одного FFmpeg до 2 часов |
| `--output "D:\Maps\test"` | явно выбрать папку проекта |
| `--json` | получить короткий машинный ответ |

Команда `py -3 video_map_builder.py --help` показывает все настройки. Для дополнительных команд: `py -3 video_map_builder.py extend --help`, `locate --help`, `frame --help`, `plan --help`, `status --help`.

## 12. Проверка после установки

При наличии FFmpeg и FFprobe можно запустить набор автоматических проверок:

```powershell
py -3 -m unittest discover -s tests -v
```

Проверяется создание карты, обработка диапазона с границами, дополнение и кэширование, восстановление после прерывания, поиск по таймкодам и получение полноразмерного кадра. Проверки работают с временным тестовым видео; пользовательские файлы не затрагивают.

## Важные ограничения

- Скрипт **не распознаёт содержание кадра**, речь или происходящее между извлечёнными кадрами. Это задача дальнейшего анализа.
- Программа использует выборку по времени; **автоматическое распознавание монтажных склеек не реализовано**.
- Установленные версии FFmpeg должны поддерживать фильтры `select`, `showinfo` и параметр `-fps_mode` (подойдут современные сборки FFmpeg).
- Повторное использование проектов опирается на путь, размер и время изменения исходного файла. При замене видео вручную с сохранением всех этих признаков это не является криптографической проверкой содержимого.
- Основной формат `manifest.json` версии 2. Ранее созданные карты можно читать и дополнять, если сохранились исходное видео и `manifest.json` предыдущей версии.
