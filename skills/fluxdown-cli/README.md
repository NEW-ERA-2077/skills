# FluxDown CLI: навык для Claude Code и Codex

Готовый навык для управления загрузками в Windows через установленную команду `fluxdown`.
Не требует MCP, Python или дополнительных программ — только рабочую утилиту FluxDown CLI и доступ агента к терминалу.

## Установка

Скопируйте **всю папку** `fluxdown-cli` (с `SKILL.md` и `references`) в каталог навыков.

Для всех проектов текущего пользователя Windows:

- Claude Code: `%USERPROFILE%\.claude\skills\fluxdown-cli\SKILL.md`
- Codex: `%USERPROFILE%\.agents\skills\fluxdown-cli\SKILL.md`

Для одного проекта:

- Claude Code: `.claude\skills\fluxdown-cli\SKILL.md`
- Codex: `.agents\skills\fluxdown-cli\SKILL.md`

## Однократная настройка доступа

В CMD выполните:

```cmd
fluxdown config set token YOUR_TOKEN
fluxdown --json list
```

**Где взять токен:** в настольном FluxDown откройте **Настройки → API Service**, включите **Enable API Service** и **Management API**. В поле **Access Token** скопируйте существующий ключ или создайте новый кнопкой генерации, если поле пустое. Затем вместо `YOUR_TOKEN` подставьте этот ключ.

Он сохранится в пользовательском конфиге CLI **открытым текстом**. Если не хотите сохранять ключ, вместо этого можно выполнить `fluxdown --token "YOUR_TOKEN" --json list` для одного вызова либо задать `set "FLUXDOWN_TOKEN=YOUR_TOKEN"` для текущего окна CMD. Учитывайте возможность появления ключа в истории терминала. Для безопасности рекомендуется использовать длинный случайный ключ доступа и не делиться им.

**Проверка:** `fluxdown ping` показывает только доступность программы и не требует токена. Проверяйте авторизацию через `fluxdown --json list`. При ошибке `24` проверьте ключ и переключатель **Management API**, при `5` — запущен ли FluxDown и верен ли адрес службы.

**Без токена:** `fluxdown add "URL" --local --dir "D:\Downloads"` скачает файл напрямую без API, но не сможет управлять задачами запущенного FluxDown. Не используйте независимый режим с тем же каталогом данных, что и у активного приложения.

## Проверка навыка

Попросите агента: «Используй навык fluxdown-cli. Скачай этот URL в D:\Media, назови файл test.jpg, сообщи путь после завершения».

Навык содержит основные команды в `SKILL.md` и подробный справочник по параметрам в `references/cli.md`. Исходники FluxDown: https://github.com/zerx-lab/FluxDown .
