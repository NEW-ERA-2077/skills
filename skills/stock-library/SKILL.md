# Stock Library — дополнение к поиску и скачиванию стоков

## Назначение

Применяй **совместно с любым** навыком, программой или службой поиска и скачивания видеостоков. Данный навык отвечает **только за локальное хранение, поиск по сохранённым описаниям и повторное использование**. Не заменяй им существующие способы поиска и загрузки.

## Расположение

Используй **корень текущего проекта, в котором запущен агент**. Создавай каталог только там, не в домашней папке и не в общем хранилище между проектами.

```text
<корень-проекта>/
└── stock-library/
    ├── catalog.jsonl
    └── stocks/
        ├── stock_00001.mp4
        └── stock_00002.mp4
```

Создавай отсутствующие `stock-library/`, `stocks/` и пустой `catalog.jsonl` при первом использовании. Внутри `stock-library/` **не создавай другие папки или служебные файлы**.

Каждая строка `catalog.jsonl` — отдельный объект JSON с полями:

```json
{"file":"stocks/stock_00001.mp4","description":"Пожилая женщина сидит у окна и медленно разминает плечи; средний план, дневной свет.","duration_s":17.2}
```

- `file` — относительный путь от `stock-library/` к существующему видео.
- `description` — конкретное описание **того, что видно в кадре**: действие, объекты, обстановка, ракурс; не выдумывай неизвестные факты.
- `duration_s` — фактическая длительность в секундах, при необходимости узнай через FFprobe.
- **Не добавляй** в записи ссылку на источник, лицензию, хеш и другие поля.

## Порядок работы

1. **До поиска новых стоков** открой `catalog.jsonl` и проверь по **смыслу**, подходят ли имеющиеся видео под конкретную сцену. Не ограничивайся совпадением ключевых слов. Если каталог большой, просматривай его частями и не отправляй целиком в контекст без необходимости.
2. При наличии подходящих кандидатов проверь их реальное содержимое через доступный инструмент просмотра или извлечения кадров. Используй существующий файл из `stocks/`; повторно не скачивай.
3. Если подходящего видео нет, используй **любой уже доступный навык поиска/скачивания стоков**. Настоящий навык не предписывает конкретный источник, загрузчик или команду.
4. После успешной загрузки помести видео в `stock-library/stocks/`, присвой уникальное имя `stock_00001.mp4`, `stock_00002.mp4` и т. д. с сохранением исходного расширения. Не переименовывай ранее добавленные файлы.
5. Проверь, не является ли новый файл уже сохранённым видео. Для очевидных совпадений можно сравнить размер и содержимое файлов; **хеш в каталог не записывай**. Добавь одну строку в `catalog.jsonl` только для нового файла. Не перезаписывай существующие записи.
6. Убедись, что строка — корректный JSON, а указанный путь существует. Если скачивание не удалось, запись не создавай.

## Границы ответственности

- Внешний поиск, получение разрешений на использование и скачивание — ответственность того навыка или инструмента, с которым работаешь; не дублируй эти функции здесь.
- Не считай сток подходящим только потому, что его описание тематически близко: решает визуальное соответствие конкретному фрагменту видео.
- Для этого навыка **не требуется отдельный поисковый скрипт или база данных**. Если библиотека станет слишком большой, оптимизацию поиска можно добавить отдельно.
