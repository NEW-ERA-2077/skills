### 🖼️ photo-upscale

Навык для улучшения качества даже сильно размытых, нечётких и малодетализированных фотографий. Восстанавливает правдоподобные визуальные детали, сохраняя естественный вид снимка. **Главная задача — повышение качества, а не увеличение разрешения с 1K до 4K или 8K.**

- Обрабатывает фотографию по перекрывающимся областям, затем отдельно улучшает значимые детали — например, лица, волосы, руки и фактуры материалов.
- Предлагает **2 или 3 прохода улучшения**; рекомендуемый вариант — два.
- Использует исходное фото как ориентир на каждом этапе, чтобы сохранять черты лица, геометрию, цвета, освещение и композицию.
- Согласует улучшенные области с оригиналом и плавно объединяет их, избегая заметных границ, повторяющихся текстур и искусственной резкости.
- Проверяет результат после каждого прохода и при необходимости исправляет дефекты обработки.
- Экспортирует результат в **PNG без потери качества** и предоставляет сведения о выполненной обработке.

### 🎬 skill-vizavi-motion

Навык для разработки выразительных анимационных роликов, продуктовых презентаций и анимированной типографики.

- Помогает продумать идею, динамическую раскадровку и переходы между сценами.
- Описывает принципы движения камеры, глубины, освещения, типографики и звука.
- Содержит дополнительные материалы по анимации интерфейсов, 3D-ресурсам, изображениям и видеообразцам.
- Требует проверки первой сборки, доработки и контроля итогового экспорта.
- По умолчанию ориентируется на **MP4, 1920 × 1080, 60 кадров/с**, если задача и доступные инструменты позволяют.

**Источник:** [vizavi.academy](https://vizavi.academy/lesson-motion/)

### 🎙️ lumean-voice

Навык для озвучивания одного или нескольких готовых TXT-сценариев через API Lumean без редактирования исходного текста.

- Помогает выбрать существующий или создать постоянный шаблон озвучки с доступным голосом и моделью синтеза речи.
- Проверяет стоимость, баланс и лимиты до отправки платных заказов, защищая от случайной повторной оплаты.
- Запускает независимые заказы параллельно, отслеживает их состояние и сохраняет прогресс для восстановления после сбоев.
- Повторно обрабатывает только ошибочные чанки и не создаёт лишние платные заказы, если работу можно продолжить.
- Скачивает готовый MP3, субтитры SRT, VTT, LRC и временные метки слов в JSON рядом с исходным TXT; при необходимости объединяет фрагменты из разных заказов с помощью FFmpeg.

### 📥 fluxdown-cli

Навык для скачивания файлов по прямым ссылкам и управления загрузками в **FluxDown на Windows** через командную строку. Работает с установленной утилитой `fluxdown`, без подключения MCP и ручного составления запросов к API.

- Скачивает отдельные файлы и пакеты ссылок, позволяет задавать каталог сохранения и имя файла.
- Управляет заданиями: показывает список и состояние, отслеживает ход загрузки, приостанавливает и возобновляет скачивание.
- Проверяет подключение к FluxDown, настройку API и авторизацию; объясняет, где получить токен и как сохранить его для CLI.
- Поддерживает самостоятельную загрузку без работающей службы API и токена, когда это допускает задача.
- Учитывает особенности CMD и PowerShell, в том числе ссылки с `&` и другими специальными символами.
- Предотвращает повторную загрузку одинаковых файлов, проверяет завершение и фактическое наличие файла на диске; не удаляет файлы без подтверждения.

**Проект:** [FluxDown](https://github.com/zerx-lab/FluxDown)<br>
**Документация CLI:** [fluxdown.zerx.dev](https://fluxdown.zerx.dev/docs/en/api/cli/)

### 🎞️ stock-library

Навык для организации локальной библиотеки видеостоков внутри текущего проекта. Дополняет любые другие навыки поиска и скачивания видеоматериалов, обеспечивая их каталогизацию и повторное использование.

- Автоматически создаёт в корне проекта папку `stock-library`, содержащую каталог `catalog.jsonl` и папку `stocks` для видео.
- Сохраняет в каталоге путь к каждому видеофайлу, краткое описание его содержимого и длительность.
- Перед поиском новых стоков проверяет локальную библиотеку на наличие подходящих материалов.
- Использует **смысловой поиск**, учитывая содержание описаний, а не только точные совпадения ключевых слов.
- Предотвращает повторное добавление уже существующих материалов и позволяет использовать одни и те же стоки в разных роликах проекта.
- Не зависит от конкретного загрузчика или сервиса поиска стоков и не требует установки дополнительных программ.
- Работает поверх уже существующих скиллов поиска и скачки видеостоков. Самостоятельно не ищет и не скачивает, только каталогизирует, проверяет наличие и обеспечивает повторное использование ранее загруженных стоков.

### 🎞️ video-map-builder

Навык для анализа видеороликов через локальный инструмент Video Map Builder. Создаёт обзорные карты из кадров с временными отметками, чтобы ИИ-агент мог изучать содержание и монтаж видео без просмотра всего ролика.

- Формирует обзорные листы с миниатюрами кадров и временными отметками, поддерживает несколько уровней детализации.
- Позволяет выбирать точные временные промежутки и извлекать дополнительные кадры только из нужного фрагмента.
- Находит кадры в готовой карте по времени и извлекает отдельные изображения в исходном разрешении.
- Дополняет существующую карту без повторной обработки готовых материалов; поддерживает кэширование и возобновление работы после сбоя.
- Сохраняет сведения о кадрах в машиночитаемых файлах и предоставляет краткие результаты команд для экономии контекста ИИ-агента.
- Работает с заранее размещённой пользователем папкой `video_map_builder`; агент не устанавливает и не переносит инструмент самостоятельно, а при отсутствии папки запрашивает её расположение.
