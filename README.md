### 🖼️ photo-upscale

Навык для улучшения качества даже сильно размытых, нечётких и малодетализированных фотографий. Восстанавливает правдоподобные визуальные детали, сохраняя естественный вид снимка. **Главная задача — повышение качества, а не увеличение разрешения с 1K до 4K или 8K.**

- Обрабатывает фотографию по перекрывающимся областям, затем отдельно улучшает значимые детали — например, лица, волосы, руки и фактуры материалов.
- Предлагает **2 или 3 прохода улучшения**; рекомендуемый вариант — два.
- Использует исходное фото как ориентир на каждом этапе, чтобы сохранять черты лица, геометрию, цвета, освещение и композицию.
- Согласует улучшенные области с оригиналом и плавно объединяет их, избегая заметных границ, повторяющихся текстур и искусственной резкости.
- Проверяет результат после каждого прохода и при необходимости исправляет дефекты обработки.
- Экспортирует результат в **PNG без потери качества** и предоставляет сведения о выполненной обработке.

### 🎬 skill-vizavi-motion

Навык для разработки выразительных анимационных роликов, продуктовых презентаций и анимированной типографики.

- Помогает продумать идею, динамическую раскадровку и переходы между сценами.
- Описывает принципы движения камеры, глубины, освещения, типографики и звука.
- Содержит дополнительные материалы по анимации интерфейсов, 3D-ресурсам, изображениям и видеообразцам.
- Требует проверки первой сборки, доработки и контроля итогового экспорта.
- По умолчанию ориентируется на **MP4, 1920 × 1080, 60 кадров/с**, если задача и доступные инструменты позволяют.

**Источник:** [vizavi.academy](https://vizavi.academy/lesson-motion/)
